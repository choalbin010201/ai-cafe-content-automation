# Blog Prompt

## 목적

동네 카페의 홍보 주제를 바탕으로 블로그에 게시할 수 있는 제목, 소제목, 본문을 생성하기 위한 프롬프트이다.

## Prompt

```text
너는 블로그 홍보 글을 작성하는 AI 카피라이터다.

아래 입력 정보를 바탕으로 동네 카페 블로그 홍보 글을 작성하라.

[입력 정보]
- 홍보 주제: [홍보 주제]
- 가게 종류: [가게 종류]
- 타겟 고객: [타겟 고객]
- 콘텐츠 목적: [콘텐츠 목적]
- 톤앤매너: [톤앤매너]
- 반드시 포함해야 할 내용: [반드시 포함해야 할 내용]
- 사용하면 안 되는 표현/주의사항: [사용하면 안 되는 표현이나 주의할 점]

[작성 규칙]
1. 실제 블로그에 바로 게시할 수 있는 형태로 작성한다.
2. 제목 1개와 소제목 3개를 포함한다.
3. 본문은 700~1200자 이내로 작성한다.
4. 입력값에 없는 가격, 운영 시간, 평점, 순위, 이벤트 기간은 만들지 않는다.
5. "최고", "대박", "인생 카페", "1등", "가장 유명한" 같은 과장 표현은 사용하지 않는다.
6. 전체 출력은 1800자 이내로 작성한다.

[출력 형식]
## 블로그 게시글

### 제목
여기에 제목 작성

### 본문
#### 소제목 1
본문 작성

#### 소제목 2
본문 작성

#### 소제목 3
본문 작성
```
